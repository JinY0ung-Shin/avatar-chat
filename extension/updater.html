확장 폴더 (선택)

확장은 자기 파일을 스스로 고칠 수 없어서, 압축을 풀어 설치한 그 폴더를 한 번 지정해 주어야 합니다. 지정한 폴더가 이 확장의 것인지는 매니페스트 키로 검증합니다. 여기서 미리 연결해 두지 않아도, 아래 업데이트 버튼을 누르면 그때 물어봅니다. 


      


      

        
파일 선택이 막혀 있을 때 — 수동 업데이트

        

          회사 보안 정책(DLP)이 브라우저의 파일 선택 창을 가로채면 위의 폴더 연결은 쓸 수
          없습니다. 아래 순서에는 파일 선택 창이 한 번도 등장하지 않습니다.
        

        
    
          
  1. 
            zip 내려받기 — Noah 설정 → 접근/보안에서 받으세요.
          
    2. 
          
  2. 윈도우 탐색기에서 압축을 풀어, 확장을 로드했던 폴더에 덮어씁니다. (브라우저 밖이라 정책과 무관합니다)
    3. 
          
  3. 
            chrome://extensions에서 이 확장 카드의 새로고침(↻)을
            누릅니다. 카드에 새 버전 번호가 보이면 끝입니다.
          
    4. 
        

        

          매번 이 과정을 반복하지 않으려면, 관리자에게 정책 설치를 요청하세요 —
          Chrome이 직접 내려받아 자동으로 갱신하므로 파일 선택 창도, 사용자 조작도 필요 없습니다.
          자세한 내용은 확장 폴더의 README를 참고하세요.
